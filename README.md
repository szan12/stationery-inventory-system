# Stationery Inventory System (SIS)

This is a group project for the Software Design Workshop course in 2021. The code was written purely in Java.

## Introduction
Stationery Inventory System (SIS) is a client-based system to facilitate the management of inventory stock. Besides, this system enables customers to make bookings on the stationery. The main objective of developing this system is to help stationery inventory operators to manage their inventory in a systematic and efficient way whilst allowing the system to handle the bookings without the presence of the admin. This system can replace the older version of stationery inventory management that uses the manual method to record inventory stock from a stock record file and only allow bookings to be made through the admin.
